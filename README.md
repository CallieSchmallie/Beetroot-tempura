# Beetroot Tempura

Granular canvas firmware for the M-VAVE FM-1, modelled on the workflow of Beetlecrab Tempera, built on M-VAVE's FM1 Open SDK.

- **Flash it:** open this repository's GitHub Pages site in Chrome or Edge (or Chrome on Android with USB-OTG), connect the FM-1 over USB and press Install.
- **Try it first:** `/simulator.html` on the same site runs the firmware in your browser.
- Details, controls and MIDI map: [BEETROOT_TEMPURA.md](BEETROOT_TEMPURA.md). FM1 Open's original readme: [README.fm1open.md](README.fm1open.md).
