Beetroot Tempura

granular canvas firmware · FM-1 simulator

Runs the real firmware code compiled for your browser, with eight demo textures loaded.

Try it

PLAY
drone the selected emitter
keys
play its placed cells at that pitch
SEQ
next emitter (E1–E4)
SELECT / MAIN
move the cursor across tracks and rows
REC
place or remove the emitter on the cursor cell
K1–K4
edit the four values on screen; PAGE flips pages
EDIT ENV LFO FX SCL GLO
grain, envelope, filter/LFO, effects, track, settings
OCT- + OCT+
switch keys between notes and cells
HOME + PLAY
all sound off

Your own sounds

Load an audio file into one of the eight tracks. The FM-1 holds about 19.5 seconds across all eight, so longer files are trimmed.

Live input: on the FM-1 this is Bluetooth audio from your phone. Here, loop a file into any track set to LIVE IN (SCL page, SOURCE).
