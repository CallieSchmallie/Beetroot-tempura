Test build 1.3: not yet tried on an FM-1

This page installs version 1.3. It has passed the build checks, the memory check and the simulator, but has not yet run on a real FM-1. The tested version, 1.2, is on the main page; if 1.3 misbehaves, install 1.2 from there the same way.

What's new
  1. A screen for every section. EDIT shows the grain window and the grain cloud, the position lanes with spray, a pitch ladder, the stereo field and the play mode. ENV draws the envelope with a dot following the sound, LFO draws the filter curve and the LFO wave, FX shows the sends, the chorus sweep, the echoes and the reverb tail. SCL shows the track's waveform with its start and end, and GLO shows the keyboard, the MIDI routing and the live-input tape.
  2. A new look. A dramatic battered-beetroot splash, smooth display fonts, gradients, rounded controls and section icons throughout.
  3. Arpeggiator. Press ARP for its page (press again for page 2). Hold ARP for half a second to switch it on or off from anywhere. Patterns: up, down, up+down, random, as played, chord. Rates 1/4 to 1/32 (with triplets), 1 to 4 octaves, gate, swing, latch and accents. It follows the tempo or MIDI clock.
  4. Your saved canvases still load; the new arpeggiator settings start switched off.
