Test build 1.2: not yet tried on an FM-1

This page installs version 1.2, the fix for 1.1's endless restarts. It has passed the build checks and the simulator but has not yet started on a real FM-1. Only install it if you can recover the unit. The tested version, 1.0, is on the main page.

What changed
  1. 1.1 left the FM-1 only 89 KB of memory to start with, so it restarted before showing anything. 1.2 starts with about the same memory as 1.0 (the build now refuses anything under 176 KB) and borrows its sound buffers only after start-up, always leaving 64 KB free for Bluetooth and USB.
  2. 1.1's fixes for crackling and freezing at high levels are kept: the audio engine stays inside its time budget, and a limiter catches redlined levels.
  3. If it misbehaves, go back to the main page and install 1.0 the same way.
